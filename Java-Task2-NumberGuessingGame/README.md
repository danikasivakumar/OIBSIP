# Number Guessing Game – Java

## Project Overview

This project is a console-based Number Guessing Game developed using Java as part of the Oasis Infobyte Java Development Internship. The game generates a random number between 1 and 100, and the user attempts to guess the number within a maximum number of attempts while receiving higher or lower hints.

## Features

* Random number generation between 1 and 100
* User input using Scanner
* "Too High!", "Too Low!", and "Correct!" responses
* Attempt counter
* Maximum attempts limit
* "You Lost!" message when the maximum attempts are reached
* Display of the correct number after losing
* Play Again option after each round
* Score tracking across multiple rounds
* Round-wise attempt summary

## Technologies Used

* Java
* Object-Oriented Programming
* Random class
* Scanner class
* While loops
* If-else statements
* VS Code
* Git and GitHub
